### Встановлення

1. Скачайте **`MASLOOPTIMIZER-v0.6.0-win-x64.zip`** зі сторінки [Releases](https://github.com/3ibravMasla/MASLOOPTIMIZER/releases/latest).
2. Розпакуйте архів у **окрему папку** (наприклад `C:\MASLOOPTIMIZER`). Програма працює **portable** — інсталятор не потрібен.
3. Запустіть `MASLOOPTIMIZER.exe` (підтвердіть UAC).
4. За бажанням увімкніть автозапуск та створіть ярлик у Налаштуваннях.

> **Де живуть ваші налаштування.** Стани твіків, логи, бекапи та `settings.json` зберігаються в `%ProgramData%\MASLOOPTIMIZER` і в реєстрі (`HKCU\Software\MASLOOPTIMIZER`). Сама папка застосунку — **лише код**: її можна заміняти цілком, нічого не втративши.

### Оновлення (автоматично, починаючи з 0.6.0)

У застосунку є **автооновлення**: він сам перевіряє GitHub Releases і показує банер «Доступне оновлення». Після натискання кнопки архів завантажується, застосунок перезапускається й **самозамінює весь ланцюг файлів** (exe + `Scripts` + `tweaks.bundle.json`), зберігаючи ваші налаштування.

### ⚠️ Одноразова міграція з 0.5.6 на 0.6.0

**Старі версії (≤ 0.5.6) автоматично НЕ оновляться.** У 0.5.6 апдейтер умів підміняти лише сам `.exe`, а 0.6.0 — це **модульна структура** з зовнішніми `.bat`-скриптами, яких у старому білді просто немає. Тому перехід робиться **один раз вручну**:

1. Трей → **🛑 Повний вихід** (закрити стару версію).
2. Скачати ZIP 0.6.0 зі сторінки [Releases](https://github.com/3ibravMasla/MASLOOPTIMIZER/releases/latest).
3. Розпакувати в **окрему папку** (наприклад `C:\MASLOOPTIMIZER`) і запустити `MASLOOPTIMIZER.exe`.
4. Стару папку можна видалити — налаштування живуть у `%ProgramData%` та реєстрі.

Далі всі оновлення приходять самі через банер. Оновлення 0.6.0 → 0.6.x уже працює автоматично.

## 🤖 Філософія проєкту: Vibe-Coding

На ринку майже немає гідних, **безкоштовних і повністю відкритих** програм для глибокого налаштування ПК, які задовольняли б потреби power-user'ів, геймерів та ентузіастів оверклоку. Тому я створив власну.

Цей проєкт — яскравий представник підходу **Vibe-Coding**:

> 🧑💻 **Людина — архітектор та ідейний натхненник.** Усі ідеї, логіка роботи Windows «під капотом», розуміння того, які твіки реально працюють, а які — маркетинг, а також вектор розвитку належать людині.
>
> 🤖 **ШІ — кодер, рефактор та UI-інженер.** Безпосереднє написання синтаксису C#, генерація XAML, рефакторинг та дрібна імплементація виконуються у тісній колаборації з AI-асистентами.

Такий симбіоз дозволяє втілювати складні низькорівневі ідеї (NT Native API, WMI, планувальник, реєстр) у реальний робочий інструмент із неймовірною швидкістю — і тримати код чистим: атомарні снапшоти, rollback, гігієна дескрипторів, подієва модель без таймерів.

🐛 **Знайшли баг?** Буду дуже радий фідбеку. Створюйте **Issues** у цьому репозиторії, якщо помітили помилку, або пропонуйте круті ідеї для покращення!

## 🚀 Розширений функціонал

### 🧩 Рушій твіків — серце програми (`TweakEngine.cs`)

- **70 модульних `.bat`-твіків** у 7 категоріях по 10 скриптів: **CPU · GPU · Gaming · Telemetry · UI · Security · Power**;
- Кожен твік — це **зовнішній `.bat`-скрипт** із двома гілками: `apply` та `restore`. Застосунок запускає його через `cmd.exe` у фоні (без вікна), перехоплює `stdout/stderr` і вважає успіхом лише `ExitCode == 0`;
- Метадані твіків живуть у [`tweaks.bundle.json`](tweaks.bundle.json) (**Version 3.1**) — вшиті в exe *та* продубльовані поруч з ним, тож каталог можна оновлювати без перезбірки;
- **Рівні ризику** `Safe` / `Medium` / `High` — впливають на сортування та обов'язкове підтвердження;
- **Живий статус** «Застосовано / Ні» через перевірку реєстрових маркерів (`CheckReg*`);
- **Снапшот-семантика:** усе, що змінюється, спершу фіксує поточний стан — щоб мати змогу відкотити;
- **Пакетне застосування** кількох твіків однією дією та фільтр по категоріях.

> 💡 Твіки — це **звичайні текстові `.bat` файли** у [`Scripts/Tweaks/`](Scripts/Tweaks). Їх можна читати, дописувати й версіонувати як звичайний код.

### 🌐 DNS-оптимізатор (`DnsEngine.cs`)

- Каталог з **37 різних пресетів** (Cloudflare, Google, Quad9, OpenDNS, Neustar, AdGuard, NextDNS, Comodo, Level3…) у групах **Speed / Security / Gaming**;
- **Багатовибірковий замір пінгу** — 3 проби на провайдера, ICMP із фолбеком TCP 53 → 443 та відсіканням сплесків (`AggregateLatency`);
- **1-Click «найшвидший»** — знаходить і застосовує найкращий DNS із бекапом оригіналу;
- **DNS-over-HTTPS (DoH)** — на Windows 11 (build ≥ 22000) для відомих провайдерів додається шифрування через `netsh dns add encryption ... autoupgrade=yes udpfallback=no`;
- **🔄 Очистити DNS-кеш** та **Reset DHCP / повернення оригінальних DNS**.

### 🗑️ Деблоат, Очищення, Автозапуск та Софт

- **Debloat UWP** ([`DebloatEngine.cs`](Engines/DebloatEngine.cs)): ~40 позицій вбудованого сміття (Copilot, Recall, Cortana, Feedback Hub, Clipchamp, Xbox-компаньйони, Zune…) та **OneDrive**, з пакетним видаленням і відновленням через Microsoft Store;
- **Глибоке очищення** ([`CleanerEngine.cs`](Engines/CleanerEngine.cs)): **19 категорій** — кеш шейдерів GPU (DX/NVIDIA/AMD/Intel/Vulkan), temp-файли, кеш Windows Update, логи CBS, Delivery Optimization, кошик (`SHQUERYRBINFO`), кеші браузерів, Prefetch, `Windows.old`, `WinSxS` через **DISM** — з безпечним та ручним режимом. Плюс **📊 аналізатор диска** у стилі WizTree з видаленням важких теч (у кошик за бажанням);
- **Менеджер автозапуску** ([`StartupEngine.cs`](Engines/StartupEngine.cs)): Registry Run/RunOnce (user + system), **планувальник завдань** (парсинг XML), папки автозапуску; вимкнення через `StartupApproved` без видалення записів;
- **Каталог софту** ([`ToolsEngine.cs`](Engines/ToolsEngine.cs)): утиліти (HWiNFO, CPU-Z, GPU-Z, MSI Afterburner, FanControl, Ryzen Master, PresentMon…) з **тихим встановленням через `winget`**, пакети VC++ Redist та DirectX Web, MAS-активація Windows і **створення ярликів на Робочому столі**.

### 🛟 Бекапи та відкат (`BackupEngine.cs`)

- Створення **точки відновлення VSS** (WMI `SystemRestore` + PowerShell-фолбек);
- **Експорт реєстру** всіх критичних ключів у timestamp-папку з `meta.json`;
- **Дзеркалювання бекапів** у `%ProgramData%\MASLOOPTIMIZER\Backups` та на вторинні диски (`MASLOOPTIMIZER_Backups`) — щоб пережити перевстановлення системи;
- Імпорт/відкат з бекапу, перегляд, сортування та видалення через окреме вікно.

### 📊 Діагностика, HUD-віджет та інтерфейс

- **Глибока апаратна діагностика** ([`DiagnosticEngine.cs`](Engines/DiagnosticEngine.cs)): статичний аудит — CPU, GPU з **64-бітним VRAM**, RAM із **DIMM-слотами**, диски з **S.M.A.R.T.**, TPM, **Secure Boot / VBS**, ReBAR, PCIe-лінк. Плюс **жива сесія сенсорів** через `LibreHardwareMonitorLib` (Ring0-драйвер відкривається один раз, опитування кожні **1.5 с**);
- **Текстовий звіт** про залізо — можна зберегти чи скопіювати;
- **Плаваючий HUD-віджет** ([`WidgetWindow.xaml`](Views/WidgetWindow.xaml)): телеметрія CPU / RAM / GPU / диск C: / мережа ↓↑ та **uptime**, швидкі дії (Restart Explorer, Purge RAM, Shutdown, Task Manager);
- **Standalone очищення ОЗП** ([`MonitorEngine.PurgeStandbyMemoryAsync()`](Engines/MonitorEngine.cs:196)): `EmptyWorkingSet` усіх процесів + `NtSetSystemInformation` (FlushModified → PurgeStandby → PurgeLowPriorityStandby) з активацією привілеїв; показує **фактично звільнені мегабайти** (чесна дельта, а не «доступна пам'ять»);
- **🧠 Тихий режим**: [`AppActivityCoordinator`](Managers/AppActivityCoordinator.cs:16) — єдине джерело правди про стан системи (видимість віджета, повноекранна гра, блокування сесії, робота від батареї). Оновлюється **лише з подій** (`SetWinEventHook`, `SystemEvents`), без таймерів. Під час гри телеметрія засинає, нові CLI не запускаються, а перевірка оновлень відкладається;
- **30 тем застосунку + 30 HUD-тем віджета** ([`ThemeEngine.cs`](Managers/ThemeEngine.cs)) — від `Cyberpunk 2077`, `Matrix`, `Tron` до `Windows 11 Light` та High-Contrast, з авто-мапінгом теми віджета;
- **Локалізація** ([`LocalizationManager.cs`](Managers/LocalizationManager.cs)): **Українська / Англійська** з fallback-ланцюгом `поточна → EN → UA → ключ` та збереженням вибору;
- **Трей** ([`TrayManager.cs`](Managers/TrayManager.cs)): відкрити оптимізатор, показати віджет, очистити ОЗП, очистити кошик, гігієна сесії (DNS + буфер обміну) та повний вихід;
- **CLI-режими**: `--widget` (тільки HUD), `--silent` (згорнуто в трей);
- **Автооновлення** ([`UpdateManager.cs`](Managers/UpdateManager.cs)): перевірка GitHub Releases API з throttle (не частіше 24 год) та модульне **`.zip`-оновлення** з прогресом;
- **Crash-dumps**: глобальні хендлери `DispatcherUnhandledException` / `AppDomain.UnhandledException` / `TaskScheduler.UnobservedTaskException` пишуть `crash_*.txt` у папку логів.

## 🏗️ Архітектура та технічний стек

```
MASLOOPTIMIZER (C# / WPF, .NET 8, self-contained, win-x64, модульний ZIP)
├── Engines/      # 9 бізнес-рушіїв: TweakEngine (ядро), Cleaner, Debloat,
│                 # Diagnostic, Dns, Startup, Tools, Backup, Monitor
├── Managers/     # 8 сервісів: AppPaths, AppLogger, LocalizationManager,
│                 # SettingsManager, ThemeEngine, AppActivityCoordinator,
│                 # TrayManager, UpdateManager
├── Models/       # TweakModel (Id, ScriptPath, Risk, CheckReg*, RegistryActions…)
├── Views/        # MainWindow (6 вкладок), WidgetWindow, DiagnosticWindow,
│                 # SettingsWindow, RestoreWindow, SafetyWindow, LogWindow
├── Languages/    # UA/EN — JSON-локалізація (EmbeddedResource)
├── Scripts/Tweaks/<Category>/*.bat   # 70 .bat-твіків (7 категорій × 10)
└── tweaks.bundle.json                # метадані 70 твіків (Version 3.1)
```

**Головне вікно — 6 вкладок:** `Твіки` · `DNS` · `Деблоат` · `Автозапуск` · `Софт` · `Очищення`.

**Залежності (NuGet):** `LibreHardwareMonitorLib 0.9.6` (сенсори Ring0) · `System.Management 10.0.2` (WMI) · `System.ServiceProcess.ServiceController 8.0.0` (служби).

**Низькорівневий шар (P/Invoke):**

| API                                                                   | DLL                 | Для чого                                     |
| --------------------------------------------------------------------- | ------------------- | -------------------------------------------- |
| `NtSetSystemInformation`                                              | `ntdll`             | трифазний purge Standby RAM                  |
| `GlobalMemoryStatusEx`                                                | `kernel32`          | чесний замір звільненої пам'яті              |
| `OpenProcessToken` / `LookupPrivilegeValue` / `AdjustTokenPrivileges` | `advapi32`          | активація привілеїв для purge                |
| `EmptyWorkingSet`                                                     | `psapi`             | скидання робочого набору процесів            |
| `SetWinEventHook`                                                     | `user32`            | подієвий детект повноекранної гри            |
| `SHQueryRecycleBinEx`                                                 | `shell32`           | розмір кошика перед очищенням                |
| WMI `Win32_*` (`Processor`, `PhysicalMemory`, `VideoController`, `Tpm`, `DiskDrive`…) | `System.Management` | аудит заліза, S.M.A.R.T., TPM |

**Якість коду:** важкі операції — виключно через `Task.Run()` з поверненням на UI через `Dispatcher`; снапшот-семантика для всього, що змінюється (реєстр, служби, DNS, NIC); захист від повторного входу (`lock` / `_busy` / `SemaphoreSlim` — зокрема single-flight у `UpdateManager`); гігієна процесних і SCM-хендлів у `finally`; подієва модель із відписками (`IWeakEventListener`), щоб статичні синглтони не тримали UI-об'єкти.

**Вимоги:** Windows 10 1809+ / 11 (x64), **.NET 8 SDK**, **права адміністратора** (`requireAdministrator` у маніфесті — програма не запуститься без UAC).

```powershell
git clone https://github.com/3ibravMasla/MASLOOPTIMIZER.git
cd MASLOOPTIMIZER

# Звичайна збірка
dotnet build -c Release --nologo -v q

# Модульна self-contained публікація (як у релізах):
# рантайм вшитий, але Scripts/ лишаються реальними .bat-файлами
dotnet publish -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=false -o .\publish\MASLOOPTIMIZER

# 1-click пакування релізного ZIP
powershell -ExecutionPolicy Bypass -File .\publish-release.ps1
```

> ⚠️ **Чому не single-file.** `TweakEngine` запускає зовнішні `.bat` **з диска** за шляхом `AppDomain.CurrentDomain.BaseDirectory\Scripts\Tweaks\...`, а каталог твіків і мови підвантажуються як окремі файли. Тому реліз — **модульна папка**, а не один exe.

**CLI-режими:**

```powershell
MASLOOPTIMIZER.exe --widget     # запуск тільки HUD-віджета (автозапуск)
MASLOOPTIMIZER.exe --silent     # повна програма, згорнута в трей
```

> ⚠️ Бінарник не підписаний кодом — Windows SmartScreen може попередити про «невідомого видавця». Це очікувано для самозбірних проєктів.

## ⚠️ Що зараз працює НЕ дуже добре (Known Issues)

Проєкт активно допрацьовується. Нижче — чесний технічний стан на поточну версію:

1. **Сумісність Windows 11 24H2.** Microsoft блокує/ігнорує частину legacy-ключів реєстру (особливо `MMCSS`, `SystemResponsiveness`, твіки конфіденційності). Твік може мати статус «Застосовано» (перевірка `Check` успішна), але **не давати фактичного ефекту** на нових збірках через політики `HKCU\Software\Policies` та «реєстрові редиректори» Windows Security. Очікуйте, що частина UI/Privacy-твіків на 24H2 — «плацебо».

2. **Пакетне застосування твіків не швидке.** Кожен `.bat` виконується послідовно у власному процесі `cmd.exe` з таймаутом **30 с**; пакетне застосування всіх 70 скриптів закономірно триває довго, а `Check`-перевірки частини твіків додатково викликають `cmd`/`PowerShell`.

3. **Локалізація — частково захардкоджена.** Рушії (Engines) і метадані повністю локалізовані через `LocalizationManager`, але **оболонка XAML-вікон** досі містить частину хардкод-рядків українською, які не перемальовуються при зміні мови. Крім того, діє політика **«RU → примусово UA + Lock»** — системну російську мову програма навмисно не підтримує.

4. **Теми — лише заміна палітри, без глибокого рестайлінгу.** Палітра обмінюється через `DynamicResource`, але частина кольорів у `MainWindow.xaml`, `WidgetWindow.xaml` та `TrayManager` (WinForms) **не входить у тему** — при швидкому перемиканні можливе «перемигування», а трей-меню завжди темне.

5. **Debloat UWP залишає порожні плитки.** Видалення глибоко вбудованих пакетів (особливо XBOX-компаньйонів та `Zune`) може лишати порожні ярлики в меню «Пуск» до перезапуску `explorer.exe`. Відновлення через Store залежить від доступності пакета в магазині.

6. **Сортування не всюди виведено в UI.** Enums `StartupSortMode`, `CleanerSortMode`, `BackupSortMode` реалізовані в рушіях, але перемикачі сортування для цих модулів відсутні в інтерфейсі.

7. **Аналізатор диска працює по вимозі.** Важкі скани (`ScanDriveHeavyItemsAsync`) виконуються повним обходом файлової системи — на HDD це може займати хвилини й помітно вантажити диск.

8. **Інші компроміси.** Модульна публікація дає ~200 файлів у папці релізу (компенсується ZIP-структурою з єдиною кореневою текою); `--silent`/`--widget` не показують помилки активації в UI; MAS-активація залежить від стороннього проєкту й може бути заблокована антивірусом.
