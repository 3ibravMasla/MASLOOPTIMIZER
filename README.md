### ⚡ Ключові можливості

* **🎛️ База 155+ перевірених твіків:** Поділ за рівнями безпеки (*UI / QoL*, *Safe*, *Medium*, *High*). Паралельна багатопотокова перевірка реального стану системи за 1–2 секунди.
* **📌 Інтерактивний Desktop HUD-віджет:** Плаваючий масштабований віджет на робочому столі з 11 стилями RGB-підсвітки, живою телеметрією CPU/GPU (температури й навантаження), виміром мережевого трафіку та швидким очищенням пам'яті/кошика.
* **🌐 Anycast DNS Benchmark:** Паралельний замір затримок (Ping) до перевірених світових Tier-1 серверів (Cloudflare, Quad9, Mullvad тощо) з фільтрацією реклами та 1-Click активацією або відкатом на DHCP.
* **📦 UWP Debloat-менеджер:** Видалення вбудованого системного мотлоху Windows (Copilot, Cortana, телеметрія, промо-ігри) без ризику зламати компоненти ОС.
* **💾 Подвійне дзеркалювання бекапів:** Автоматичне збереження копій реєстру в захищену директорію `ProgramData` з автодублюванням на другий фізичний накопичувач (D:, E:) для гарантованого відкату.
* **🚀 Менеджер автозапуску:** Повний аудит гілок Run (32/64-bit), спільних папок Startup та сторонніх завдань Планувальника Windows.
* **🛠️ Бібліотека утиліт:** Встановлення діагностичного софту через тихий Winget-рушій, оновлення DirectX, Visual C++ All-in-One та автономні антивірусні сканери без встановлення фонових служб.
* **📁 Експорт та імпорт пресетів:** Збереження власного профілю налаштувань у `.json` файл для 1-Click розгортання на іншому комп'ютері.

### 📥 Завантаження та запуск

1. Перейдіть у розділ **[Releases](https://github.com/3ibravMasla/MASLOOPTIMIZER/releases/latest)**.
2. Завантажте останній файл `MASLOOPTIMIZER.exe` (або zip-архів релізу).
3. Запустіть файл **від імені адміністратора** (необхідно для коректного редагування системних ключів реєстру та служб).

### 🛡️ Безпека та Відкат

Програма містить вбудовані запобіжники:
* **Перший запуск:** Пропонує створення точки відновлення Windows (VSS) та повний бекап задіяних гілок реєстру.
* **Відновлення:** Кнопка **«🔄 Відкат»** у шапці головного вікна дозволяє повернути оригінальні параметри з будь-якого раніше збереженого архіву в 1 клік.
