## 🚀 Основний функціонал та модулі

### 1. 🎮 Game Mode & Latency Boost (`GameModeEngine`)
* **1-Click Game Boost:** Миттєва підготовка системи до запуску важких ігор.
* **Standby RAM Purge:** Скидання кешу оперативної пам'яті через нативні виклики `ntdll.dll` (`NtSetSystemInformation` / `MemoryPurgeStandbyList`), що усуває мікрофризи та вивільняє гігабайти пам'яті без перезавантаження.
* **Тимчасове зупинення фонових служб:** Заморозка служб телеметрії, індексації пошуку (`WSearch`), диспетчера друку (`Spooler`), `SysMain` та фонових апдейтерів на час сесії.
* **Автоматичний відкат:** Повне відновлення вихідного стану всіх служб та початкової схеми електроживлення після деактивації режиму.

### 2. ⚡ Вбудований менеджер переривань MSI (`MsiEngine`)
* **Аналог MSI Utility v3:** Сканування шини PCI та переведення відеокарт (NVIDIA/AMD), NVMe SSD, контролерів USB та мережевих адаптерів у векторний режим **Message Signaled-Based Interrupts (MSI)**.
* **Affinity Priority:** Встановлення високого пріоритету переривань (`High Priority`) для GPU та мережевих плат з метою зниження Input Lag миші та стабілізації Frametime.
* **Апаратний захист:** Автоматичне блокування модифікацій системних мостів (PCI Bridges) для запобігання нестабільності системи.

### 3. 🌐 Мережа & TCP/IP Latency Engine (`NetworkEngine`)
* **Вимкнення алгоритму Nagle:** Активація `TCPNoDelay` та встановлення `TcpAckFrequency = 1` для миттєвої відправки дрібних пакетів у мережевих онлайн-іграх.
* **Глобальний тюнінг стека:** Налаштування провайдера перевантажень `CTCP` / `CUBIC`, зняття 20% ліміту пропускної здатності планувальника QoS (`NonBestEffortLimit = 0`).
* **Оптимізація адаптера (NIC):** 1-Click вимкнення енергозберігаючих режимів (*Energy Efficient Ethernet*, *Green Ethernet*, *Interrupt Moderation*) та розширення кільцевих буферів прийому/передачі.
* **1-Click Network Reset:** Аварійне скидання маршрутизації, Winsock, ARP та конфігурації IP при мережевих збоях.

### 4. 🏆 Аудит системи «MASL Health Score» (`HealthEngine`)
* **Комплексна перевірка (0–100%):** Оцінка готовності системи за 10 критичними параметрами:
  * Статус VBS / Core Isolation (HVCI)
  * Апаратне планування GPU (HAGS)
  * Підтримка команди TRIM для NVMe / SATA SSD
  * Схема електроживлення (Ultimate / High Performance)
  * Фоновий запис GameDVR
  * Пріоритети Multimedia Tasks/Games
  * Тюнінг мережевого стека та режим MSI
* **1-Click Fix All:** Виправлення всіх невідповідностей системи в один клік.

### 5. 🔍 Апаратна діагностика та сенсори (`DiagnosticEngine`)
* **Детальна інформація про залізо:**
  * **Процесор:** архітектура, конфігурація ядер/потоків, L3-кеш, базова/максимальна частота.
  * **Відеокарта:** модель, VRAM, версія драйвера, статус Resizable BAR.
  * **RAM:** обсяг, тип (DDR4 / DDR5), реальна швидкість у MT/s, конфігурація модулів по слотах DIMM.
  * **Накопичувачі:** томи, типи шин (NVMe, SATA, USB), статус SMART.
  * **Плата та BIOS:** версія прошивки, дата релізу, статус Secure Boot.

### 6. 🌐 DNS Benchmark & Оптимізатор (`DnsEngine`)
* Паралельне тестування пінгу до швидких Anycast DNS-серверів (Cloudflare, Google, Gcore, OpenDNS, Control D тощо).
* Сортування за мінімальною затримкою та застосування обраного DNS в один клік або повернення до DHCP.

### 7. 🚀 Автозапуск, Деблоат та Очищення
* **Startup Manager:** Керування автозавантаженням із фільтрацією за джерелами (HKCU Run, HKLM Run, Task Scheduler, Startup Folder) та вимкненням непотрібного софту.
* **UWP Debloat:** Видалення попередньо встановлених додатків Windows, рекламних модулів і служб телеметрії.
* **Disk Cleaner:** Безпечне очищення кешу браузерів, тимчасових файлів Windows Temp, Prefetch та застарілих логів оновлень.

### 8. 📌 Плаваючий HUD-віджет та Кастомізація
* **Desktop HUD Widget:** Компактний віджет на робочому столі з відображенням стану системи, навантаження та кнопкою швидкого очищення Standby RAM.
* **25+ тем оформлення:** Підтримка тем від класичних (Windows XP Luna, Win7 Aero, 98 Classic) до темних і кіберпанк-палітр (Cyber Stealth, Monokai, Dracula, Nord, Cyberpunk 2077).
* **UI Scaling:** Налаштування масштабування інтерфейсу (від 75% до 150%) для моніторів із будь-якою роздільною здатністю (1080p, 2K, 4K).
